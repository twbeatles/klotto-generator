## 🌟 소개 및 주요 특징

**로또·연금복권 프로**는 통계적 기법과 지능형 필터링 알고리즘을 활용하여 최적의 복권 조합을 추천하고 당첨 이력을 체계적으로 관리할 수 있는 PyQt6 기반의 데스크톱 애플리케이션입니다.

- **🎲 로또 6/45 & 연금복권 720+ 완벽 지원**: 두 가지 복권의 특성에 맞춘 전용 알고리즘과 통계 화면 제공
- **🧠 다채로운 전략 엔진**: 앙상블 가중치, 베이지안 스무딩, 휠링 시스템, 조 로테이션 등 20여 종의 수학·통계적 전략 탑재
- **📊 과거 시뮬레이션 (Backtest)**: 과거 실제 당첨 이력을 기준으로 원하는 전략들의 ROI(수익률)와 적중률을 사전에 시뮬레이션 비교
- **📅 장기 캠페인 관리**: 단발성 생성을 넘어 N주 차에 걸친 분산 시드 캠페인 티켓 일괄 생성
- **📷 실물 복권 QR 스캔**: 웹캠이나 이미지로 복권 용지의 QR 코드를 인식하여 즉시 당첨 여부 확인
- **💾 안전한 데이터 관리**: 단일 통합 상태(`app_state.json`) 저장, 손상 감지 시 원본 보존 후 안전 시작, 전체 DB 엑셀(.xlsx) 및 CSV(수식 인젝션 방지 적용) 내보내기 지원
- **🎨 사용자 친화적 UI**: 라이트/다크 테마 전환, 직관적인 좌측 내비게이션 및 반응형 테이블 레이아웃

## 🚀 빠른 시작 (설치 및 실행)

### 1. 요구 사항
- **Python**: 3.10 이상 권장
- **운영체제**: Windows, macOS, Linux 지원

### 2. 설치

가상환경을 생성하고 필요한 패키지를 설치합니다.

```bash
# 1. 저장소 클론 및 이동
cd klotto-generator

# 2. 가상환경 생성 및 활성화 (Windows 기준)
python -m venv .venv
.venv\Scripts\activate

# (macOS/Linux의 경우: source .venv/bin/activate)

# 3. 필수 의존성 패키지 설치
pip install -r requirements.txt

# 4. (권장) QR 코드 스캔 및 엑셀 내보내기용 선택 패키지 설치
pip install -r requirements-optional.txt
```

> [!TIP]
> **선택 패키지(`requirements-optional.txt`) 포함 항목**:
> - `opencv-python`, `pyzbar` : 웹캠 및 QR 코드 이미지 인식 기능
> - `openpyxl` : 전체 당첨번호 데이터베이스 엑셀(.xlsx) 내보내기 기능

### 3. 프로그램 실행

```bash
python run_klotto.py
```

> [!IMPORTANT]
> **첫 실행 시 필수 권장 사항**:
> 프로그램을 처음 띄운 후, 좌측 메뉴의 **`설정/동기화`** 페이지로 이동하여 **[지금 동기화]** 버튼을 클릭하세요. 동행복권 최신 회차 데이터를 가져와야 AI 추천 및 전략 시뮬레이션 기능을 온전히 사용할 수 있습니다.

### 1. 로또 6/45 번호 생성

원하는 전략과 사용자 조건(고정수, 제외수, 필터 등)을 결합하여 로또 6/45 조합을 생성합니다.

```
[ 상단: 최신 당첨 회차 및 당첨번호 안내 바 ]
[ 좌측: 전략 선택 및 정밀 필터 설정 ]   [ 우측: 세트 수, 고정수, 제외수, 대상 회차 ]
[ 중앙: 생성된 조합 결과 테이블 (순위, 점수, 합계, 조합 진단 분석) ]
[ 하단 액션: [히스토리 저장] [선택 즐겨찾기] [전체 티켓북 추가] ]
```

#### 🔹 기본 생성 방법
1. **세트 수 설정**: 한 번에 추출할 게임 수 (1 ~ 20세트)를 지정합니다.
2. **고정수 / 제외수 지정 (선택)**:
   - 반드시 포함할 번호와 제외할 번호를 쉼표나 하이픈 범위로 입력합니다.
   - *입력 예시*: `1, 7, 12` 또는 `3-6, 20, 35`
3. **전략 선택**:
   - `앙상블 가중치`, `컨센서스 포트폴리오`, `베이지안 스무딩`, `모멘텀 추세`, `휠링(축약)` 등 원하는 알고리즘을 선택합니다.
4. **필터 세부 조정**:
   - **홀짝 비율**: 예) 홀수 3개 : 짝수 3개 (3:3) 또는 2:4
   - **고저 비율**: 1~22(저), 23~45(고) 분포 비율 설정
   - **총합 구간**: 6개 숫자의 합계 허용 범위 (기본: 100 ~ 175)
   - **AC값**: 조합의 복잡도 지수 (기본: 7 이상 권장)
   - **연속 번호 제한**: 예) 2개 초과 연속 번호(`12, 13, 14`) 방지
5. **[번호 생성] 클릭**:
   - 생성된 조합마다 **추천 점수(Score)**, **총합(Sum)**, **페어 시너지/프로파일/공백 지수** 진단 결과가 표시됩니다.

#### 🔹 캠페인(장기 분산 구매) 생성
- **[캠페인 시작 회차]**, **[캠페인 주차]**(예: 4주), **[주당 세트]**(예: 5세트)를 지정하고 **[캠페인 생성]**을 누르면, 주차별로 시드가 자동 분산된 티켓이 생성되어 **티켓북 및 캠페인 목록**에 한 번에 등록됩니다.
- 캠페인 총 티켓은 **300장 상한**을 초과할 수 없습니다. 초과 설정 시 생성이 차단됩니다.

#### 🔹 결과 활용
- **[히스토리 저장]**: 생성 로그에 일괄 기록합니다.
- **[선택 즐겨찾기]**: 마음에 드는 조합을 선택하여 즐겨찾기 목록에 영구 보관합니다.
- **[전체 티켓북 추가]**: 대상 회차의 구매 예정 티켓으로 등록하여 추후 자동 당첨 확인을 수행합니다.

### 2. 연금복권 720+ 추천 및 캠페인

연금복권 720+ 전용 데이터 분석과 조/자리별 전략을 통해 최적의 번호를 추출합니다.

```
[ 상단: 연금복권 데이터 상태 & 조별 출현 빈도 / 각 자리별 1~3위 핫 넘버 요약표 ]
[ 좌측: 연금복권 전략, 분석 강도, 자리 고정/제외, 숫자합, 유니크 필터 설정 ]
[ 우측: 단일 생성 및 연금복권 다주차 캠페인 설정 ]
[ 하단: 추출 번호 리스트, 확장 조(1~5조 동일번호 세트) 일괄 저장, CSV 내보내기 ]
```

#### 🔹 추천 옵션 설정
- **전략 선택**:
  - `혼합 균형`: 조/자리/최근 흐름을 종합 반영한 표준 전략 (권장)
  - `자리별 강세`: 1~6자리 각각의 빈출 번호 집중 공략
  - `끝자리 적중형`: 하위 등수 당첨 확률을 높이는 뒤쪽 3~4자리 집중형
  - `조 로테이션` / `공백 반등` / `보너스 흐름` 등
- **분석 강도**: `빠름`, `기본`, `정밀`, `직접(Custom)` 중 선택
- **조 선택**: 예) `1, 3, 5` (특정 조만 한정 추출)
- **자리별 고정 / 제외 숫자 문법**:
  - **자리 고정**: `1=0, 6=7` (1번째 자리는 0, 6번째 자리는 7로 고정)
  - **자리 제외**: `2=9,8; 5=0` (2번째 자리는 9와 8 제외, 5번째 자리는 0 제외)
- **정밀 필터**: 각 자리의 숫자합(0~54), 홀수 자리 수, 5 이상 고숫자 개수, 최소 숫자 종류(Unique) 설정

#### 🔹 연금복권 특화 기능
- **세트 구매(확장 조 전체 저장)**: 연금복권 1등 및 2등(동일 번호 타 조 4장) 동시 당첨을 노리기 위해 1~5조 전체 번호 세트로 즉시 저장할 수 있습니다.
- **CSV 내보내기**: 스프레드시트 수식 인젝션 방지가 적용된 표준 CSV 형식으로 저장 목록을 추출합니다.

### 3. 당첨 통계 (핫/콜드 번호)

동기화된 SQLite 데이터베이스를 기반으로 역대 당첨 데이터의 심층 통계를 시각적으로 제공합니다.

- **핫 넘버 (Hot Numbers)**: 역대 가장 많이 출현한 상위 10개 번호와 출현 횟수
- **콜드 넘버 (Cold Numbers)**: 가장 오랫동안 출현하지 않았거나 누적 출현이 적은 하위 10개 번호
- **최근 회차 결과 테이블**: 최근 12회차의 당첨 번호, 보너스 번호, 추첨일 리스트 제공

### 4. AI 지능형 추천

최근 회차들의 성과 흐름을 머신러닝/앙상블 방식으로 실시간 역추적하여 현재 시점에서 가장 기대값이 높은 전략을 자동으로 선정해 번호를 생성합니다.

- **자동 전략 종류**:
  - `auto_recent_top`: 최근 N회 기준 백테스트 성과 1위 전략을 자동 선택하여 추출
  - `auto_ensemble_top3`: 최근 성과 상위 3개 전략의 가중치를 결합한 자동 앙상블
- **데이터 무결성 게이트(Data Gate)**:
  - AI 분석의 정확도를 위해 SQLite DB에 누락 없는 전체 회차가 보관된 `full` 상태에서만 활성화됩니다.
  - 비활성화 상태인 경우 안내 툴팁과 함께 설정 페이지에서 무결성 검사를 수행할 수 있습니다.

### 5. 전략 시뮬레이션 (백테스트)

"만약 지난 30회차 동안 이 전략으로 매주 5장씩 샀다면 얼마를 벌었을까?"를 완벽하게 검증합니다.

```
[ 시뮬레이션 설정: 시작 회차(예: 1100), 종료 회차(예: 1130), 회차당 구매 수량 ]
[ 비교 대상 전략 다중 선택 (Ctrl/Shift 클릭으로 여러 전략 동시 지정) ]
[ [시뮬레이션 실행] -> 백그라운드 멀티스레드 고속 연산 ]
[ 결과 테이블: 전략명 | ROI(수익률) | 적중률 | 처리 회차 | 총비용 | 총당첨금 ]
```

- **ROI(투자수익률) 및 적중률 계산**: 실제 등수별 당첨금 기준 수익률 계산
- **멀티 전략 벤치마크**: 최대 5개 전략을 동일한 과거 구간에서 정면 승부 비교 가능

### 6. 당첨 확인 & QR 코드 스캐너

내가 보관한 번호들과 실제 추첨 결과를 손쉽게 대조합니다.

#### 🔹 보관함 대조
- 좌측에서 `즐겨찾기`, `히스토리`, `티켓북` 중 원하는 소스를 선택합니다.
- 특정 번호를 클릭하고 **[당첨 확인]**을 누르면, 역대 모든 회차(또는 해당 티켓의 대상 회차)와의 일치 개수 및 당첨 등수(1~5등, 보너스 일치)를 표로 정리해 줍니다.

#### 🔹 📷 QR 코드 스캐너
- 복권 용지에 인쇄된 QR 코드를 활용한 고속 당첨 확인 기능입니다.
- **[QR 스캔]** 버튼을 클릭한 후:
  1. PC에 연결된 **웹캠 카메라**로 실물 복권의 QR 코드를 비추거나,
  2. QR 코드가 포함된 **이미지 파일**을 불러옵니다.
- 자동으로 회차와 구매 번호 5게임을 파싱하여 동행복권 결과와 대조 후 등수를 팝업으로 안내합니다.
- 형식이 깨진 게임은 건너뛰고 제외 개수를 확인 창에 표시합니다. 로또 QR이 아닌 코드를 비추면
  안내 메시지가 표시되고, 읽을 수 없는 QR은 오류 없이 다시 시도할 수 있습니다.

### 7. 데이터 관리 (백업 및 엑셀 내보내기)

앱 내에 누적된 모든 데이터의 조회, 편집, 백업, 외부 내보내기를 총괄합니다.

- **데이터 탭**: `즐겨찾기(Favorites)`, `생성기록(History)`, `티켓북(Tickets)`, `로또 캠페인`, `연금복권 티켓`, `연금복권 캠페인`
- **전체 백업 내보내기 / 가져오기**:
  - 앱의 모든 설정과 데이터를 `lotto_pension_pro_backup_v5_*.json` 파일로 안전하게 내보냅니다.
  - 가져오기 시 병합(Merge) 또는 덮어쓰기(Overwrite) 방식을 선택할 수 있으며,
    가져오기 전 현재 상태는 `app_state.preimport-*.json` 스냅샷으로 자동 보존됩니다.
- **📊 당첨 DB 엑셀(.xlsx) 내보내기**:
  - 버튼 클릭 한 번으로 SQLite에 저장된 역대 전체 회차 당첨번호, 날짜, 1등 당첨자 수, 1등 당첨금, 총 판매액 데이터를 스타일이 적용된 깔끔한 엑셀 파일(`lotto_history_YYYYMMDD_HHMMSS.xlsx`)로 저장합니다.

### 8. 환경설정 및 데이터 동기화

앱의 네트워크 연결 및 데이터 무결성을 관리하는 제어판입니다.

- **데이터 상태 진단 (Data Health)**:
  - 로또 및 연금복권 데이터의 최신 회차 일치 여부, 누락된 회차(Missing Draws) 현황 표시
- **동기화 동작**:
  - **[지금 동기화]**: 최근 회차 및 최근 누락된 회차를 고속으로 수집합니다.
  - **[전체 무결성 검사/복구]**: 1회차부터 최신 회차까지 누락된 모든 구간을 검사하여 복구합니다.
  - 수집 중에는 진행률 표시줄에 `완료/전체`가 표시되며, **[동기화 취소]**로 언제든 중단할 수 있습니다.
    일시적 네트워크 오류는 회차당 1회 자동 재시도합니다.
- **프록시(Proxy) 설정**: 기업망이나 프록시 환경에서 `http://127.0.0.1:8080` 형식으로 네트워크 프록시를 지정할 수 있습니다.
- **알림 설정**: 새 회차 결과 반영 알림 토글
- **테마 전환**: 라이트 모드 ☀️ / 다크 모드 🌙 전환

## ❓ 자주 묻는 질문 (FAQ) & 문제 해결

### Q1. AI 추천이나 전략 시뮬레이션 버튼이 비활성화(회색)되어 있어요.
> **A.** AI 추천과 백테스트는 데이터 신뢰도를 위해 **전체 회차 당첨 이력**이 확보되어야 합니다.<br>
> 좌측 메뉴의 **`[설정/동기화]`** 페이지로 이동하여 **[지금 동기화]** 또는 **[전체 무결성 검사/복구]**를 실행해 주세요. 상태가 `full`로 바뀌면 즉시 잠금이 해제됩니다.

### Q2. QR 코드 스캔 또는 엑셀 내보내기를 누르면 오류가 발생해요.
> **A.** 필수 패키지 외에 선택 패키지(`opencv-python`, `pyzbar`, `openpyxl`)가 설치되지 않은 경우입니다. 터미널에서 다음 명령어를 실행해 주세요:
> ```bash
> pip install -r requirements-optional.txt
> ```

### Q3. 내가 저장한 번호와 설정 파일은 어디에 보관되나요?
> **A.** 사용자 홈 디렉토리의 아래 경로에 안전하게 보관됩니다:
> - **Windows**: `C:\Users\<사용자명>\.lotto_generator\`
> - **macOS/Linux**: `~/.lotto_generator/`
> - 주요 파일: `app_state.json` (통합 상태), `lotto_history.db` (당첨 SQLite DB)

### Q4. 이전 버전에서 사용하던 데이터가 사라지나요?
> **A.** 아닙니다. 앱 실행 시 기존 레거시 파일(`favorites.json`, `history.json`, `settings.json`)을 자동으로 감지하여 신규 통합 상태(`app_state.json`)로 안전하게 자동 마이그레이션합니다.
