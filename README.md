## 🌟 소개 및 주요 특징

**로또·연금복권 프로**는 과거 당첨 흐름을 바탕으로 복권 번호를 추천하고 당첨 여부를 체계적으로 관리할 수 있는 데스크톱 앱입니다.

- **🎲 로또 6/45 & 연금복권 720+ 완벽 지원**: 두 가지 복권의 특성에 맞춘 전용 추천 방식과 통계 화면 제공
- **🧠 다양한 번호 추천 방식**: 여러 신호를 함께 보는 방식, 자리별 강세, 조 고르기 등 20여 종 탑재
- **📊 지난 결과로 미리 시험**: 과거 실제 당첨 기록을 기준으로 원하는 방식들의 수익률과 맞힌 비율을 사전에 비교
- **📅 여러 주 묶음 구매**: 한 번 만들기로 그치지 않고 몇 주에 걸쳐 나눠 살 번호를 한 번에 준비
- **📷 실물 복권 QR 확인**: 웹캠이나 이미지로 복권 용지의 QR 코드를 읽어 즉시 당첨 여부 확인
- **💾 안전한 번호 관리**: 번호와 설정을 하나의 파일(`app_state.json`)에 저장, 문제 발생 시 원본 보존 후 안전 시작, 당첨 번호 엑셀(.xlsx) 및 파일 저장 지원
- **🎨 쓰기 편한 화면**: 밝기 바꾸기, 직관적인 왼쪽 메뉴 및 반응형 표 레이아웃

## 🚀 빠른 시작 (설치 및 실행)

### 1. 요구 사항
- **Python**: 3.10 이상 권장
- **운영체제**: Windows, macOS, Linux 지원

### 2. 설치

가상환경을 생성하고 필요한 패키지를 설치합니다.

```bash
# 1. 저장소 클론 및 이동
cd klotto-generator

# 2. 가상환경 생성 및 활성화 (Windows 기준)
python -m venv .venv
.venv\Scripts\activate

# (macOS/Linux의 경우: source .venv/bin/activate)

# 3. 필수 의존성 패키지 설치
pip install -r requirements.txt

# 4. (권장) QR 코드 스캔 및 엑셀 내보내기용 선택 패키지 설치
pip install -r requirements-optional.txt
```

> [!TIP]
> **선택 패키지(`requirements-optional.txt`) 포함 항목**:
> - `opencv-python`, `pyzbar` : 웹캠 및 QR 코드 이미지 인식 기능
> - `openpyxl` : 전체 당첨번호 데이터베이스 엑셀(.xlsx) 내보내기 기능

### 3. 프로그램 실행

```bash
python run_klotto.py
```

> [!IMPORTANT]
> **첫 실행 시 필수 권장 사항**:
> 프로그램을 처음 띄운 후, 왼쪽 메뉴의 **`설정·최신 정보`** 화면으로 이동하여 **[최신 정보 가져오기]** 버튼을 누르세요. 동행복권 최신 회차 정보를 가져와야 AI 추천 및 지난 결과 시험 기능을 온전히 쓸 수 있습니다.

### 1. 로또 6/45 번호 생성

원하는 방식과 조건(꼭 넣을 번호, 빼고 싶은 번호 등)을 함께 정해 로또 6/45 조합을 만듭니다.

```
[ 상단: 최신 당첨 회차 및 당첨번호 안내 ]
[ 좌측: 번호 만드는 방식 설정 ]   [ 우측: 만들 개수, 꼭 넣을 번호, 빼고 싶은 번호, 구매할 회차 ]
[ 중앙: 만든 조합 결과 표 (순서, 번호, 추천도, 번호 합, 한눈에 보기) ]
[ 하단: [기록에 저장] [고른 번호 즐겨찾기] [구매 목록에 담기] ]
```

#### 🔹 기본 만들기 방법
1. **만들 개수**: 한 번에 만들 게임 수 (1 ~ 20개)를 정합니다.
2. **꼭 넣을 번호 / 빼고 싶은 번호 (선택)**:
   - 꼭 넣을 번호와 빼고 싶은 번호를 쉼표나 하이픈 범위로 입력합니다.
   - *입력 예시*: `1, 7, 12` 또는 `3-6, 20, 35`
3. **만드는 방식 고르기**:
   - 목록에서 원하는 방식을 고릅니다. 각 방식 옆에 어떤 점을 보는지 짧은 설명이 함께 나옵니다.
4. **조건 다듬기 (선택)**:
   - **홀수 개수 / 큰 수 개수 / 번호 합 범위 / 번호 퍼짐 정도 / 이어지는 번호 제한 / 끝자리 종류 수** 등을 정할 수 있습니다. 비워두면 알아서 만듭니다.
5. **[번호 생성] 누르기**:
   - 만든 조합마다 **추천도(점수)**, **번호 합**, **한눈에 보기**(함께 잘 나오는지·고른 정도·간격) 결과가 표시됩니다.

#### 🔹 여러 주 묶음 구매
- **[시작 회차]**, **[이어서 할 주 수]**(예: 4주), **[주마다 개수]**(예: 5개)를 정하고 **[묶음으로 만들기]**를 누르면, 주마다 번호를 나눠 만들어 **구매 목록과 묶음 목록**에 한 번에 담습니다.
- 묶음 번호는 **300개 한도**를 넘을 수 없습니다. 넘치게 정하면 만들기가 막힙니다.

#### 🔹 결과 활용
- **[기록에 저장]**: 만든 번호를 만든 기록에 한 번에 남깁니다.
- **[고른 번호 즐겨찾기]**: 마음에 드는 조합을 골라 즐겨찾기에 보관합니다.
- **[구매 목록에 담기]**: 구매할 회차의 살 번호로 등록해 두면 나중에 당첨 여부를 확인할 수 있습니다.

### 2. 연금복권 720+ 추천 및 묶음 구매

연금복권 720+ 흐름을 보고 조와 자리별로 어울리는 번호를 추천합니다.

```
[ 상단: 연금복권 당첨 정보 & 조별 나온 횟수 / 자리별 자주 나온 숫자 요약표 ]
[ 좌측: 추천 방식, 꼼꼼히 보기 정도, 자리 숫자 정하기·빼기, 자리 수 조건 설정 ]
[ 우측: 낱개 추천 및 여러 회차 묶음 설정 ]
[ 하단: 추천 번호 목록, 같은 번호 5개 조 모두 저장, 파일로 저장 ]
```

#### 🔹 추천 조건 정하기
- **추천 방식 고르기**:
  - `혼합 균형`: 조·자리·최근 흐름을 고르게 보는 기본 방식 (권장)
  - `자리별 강세`: 1~6자리 각각 자주 나온 숫자를 많이 반영
  - `끝자리 적중형`: 낮은 등수와 이어지는 뒤쪽 3~4자리를 많이 반영
  - `조 로테이션` / `공백 반등` / `보너스 흐름` 등
- **얼마나 꼼꼼히 볼지**: `빠르게`, `보통`, `꼼꼼하게`, `직접 정하기` 중 선택
- **원하는 조**: 예) `1, 3, 5` (고른 조에서만 추천)
- **자리 숫자 정하기 / 빼기 입력 방법**:
  - **정해둘 자리 숫자**: `1=0, 6=7` (1번째 자리는 0, 6번째 자리는 7로 정하기)
  - **빼고 싶은 자리 숫자**: `2=9,8` (2번째 자리에서 9와 8 빼기)
- **자리 수 조건**: 여섯 자리 합(0~54), 홀수인 자리 수, 5 이상인 자리 수, 서로 다른 숫자 최소 개수 등 설정

#### 🔹 연금복권 특화 기능
- **같은 번호 5개 조 모두 저장**: 연금복권 1등과 2등(같은 번호의 다른 조)을 함께 노릴 때 1~5조 번호를 한 번에 저장할 수 있습니다.
- **파일로 저장**: 저장 목록을 엑셀에서 여는 파일(CSV) 형태로 저장합니다.

### 3. 당첨 통계 (자주·뜸한 번호)

가져온 당첨 기록을 바탕으로 역대 흐름을 한눈에 보여줍니다.

- **자주 나온 번호**: 역대 가장 많이 나온 상위 10개 번호와 나온 횟수
- **오래 안 나온 번호**: 오랫동안 안 나왔거나 누적 횟수가 적은 하위 10개 번호
- **최근 회차 결과 표**: 최근 12회차의 당첨 번호, 보너스 번호, 추첨일 목록 제공

### 4. AI 지능형 추천

최근 흐름을 되짚어 지금 시점에 가장 잘 맞는 방식을 자동으로 골라 번호를 만듭니다.

- **자동으로 고르는 방식**:
  - `자동 선택(최근 상위 1개)`: 최근 흐름에서 가장 성적이 좋은 방식을 자동으로 선택
  - `자동 앙상블(상위 3개)`: 최근 성적 상위 3개 방식을 섞어서 추천
- **이용 조건**:
  - 당첨 정보를 빠짐없이 모두 가져온 뒤에 쓸 수 있습니다.
  - 버튼이 눌리지 않으면 설정 화면에서 최신 정보를 가져오세요.

### 5. 지난 결과로 시험

"지난 30회차 동안 이 방식으로 매주 5개씩 샀다면 어땠을까?"를 미리 확인합니다.

```
[ 시험 설정: 시작 회차(예: 1100), 마지막 회차(예: 1130), 회차마다 살 개수 ]
[ 비교할 방식 여러 개 고르기 (Ctrl/Shift 클릭으로 동시 지정) ]
[ [시험 시작]을 누르면 과거 기록으로 계산 ]
[ 결과 표: 방식 | 수익률 | 맞힌 비율 | 쓴 회차 | 쓴 금액 | 받은 상금 ]
```

- **수익률 및 맞힌 비율 계산**: 실제 등수별 당첨금 기준으로 계산
- **여러 방식 한 번에 비교**: 최대 5개 방식을 같은 과거 구간에서 나란히 비교 가능

### 6. 당첨 확인 & QR 코드 스캐너

내가 보관한 번호들과 실제 추첨 결과를 손쉽게 대조합니다.

#### 🔹 보관함 대조
- 왼쪽에서 `즐겨찾기`, `만든 기록`, `구매 목록` 중 원하는 곳을 고릅니다.
- 번호를 고르고 **[당첨 확인하기]**를 누르면, 역대 모든 회차(또는 산 회차)와의 맞은 개수와 당첨 등수(1~5등, 보너스 일치)를 표로 보여줍니다.

#### 🔹 📷 QR 코드로 확인
- 복권 용지에 인쇄된 QR 코드로 빠르게 당첨을 확인하는 기능입니다.
- **[QR로 확인하기]** 버튼을 누른 후:
  1. PC에 연결된 **웹캠 카메라**로 실물 복권의 QR 코드를 비추거나,
  2. QR 코드가 담긴 **이미지 파일**을 불러옵니다.
- 회차와 산 번호 5게임을 자동으로 읽어 동행복권 결과와 비교한 뒤 등수를 팝업으로 알려줍니다.
- 읽히지 않는 게임은 건너뛰고 제외 개수를 확인 창에 표시합니다. 로또 QR이 아니면
  안내 메시지가 나오고, 읽을 수 없는 QR은 다시 시도할 수 있습니다.

### 7. 내 번호 관리 (저장·엑셀)

앱에 쌓인 번호와 설정을 한곳에서 보고, 저장하고, 지울 수 있습니다.

- **목록 탭**: `즐겨찾기`, `만든 기록`, `구매 목록`, `묶음 구매`, `연금복권 번호`, `연금복권 묶음`
- **전체 저장하기 / 불러오기**:
  - 앱의 번호와 설정을 `lotto_pension_pro_backup_v5_*.json` 파일로 저장합니다.
  - 불러올 때는 기존 목록에 합치기 또는 모두 지우고 덮어쓰기 중 고를 수 있으며,
    불러오기 전 상태는 자동으로 따로 보관됩니다.
  - 합치기는 같은 파일을 여러 번 불러와도 구매 개수가 늘어나지 않으며,
    현재 앱의 설정(전략·알림·동기화 상태)은 그대로 유지됩니다. 불러오기 결과는 건수로 알려줍니다.
- **불러오기 전으로 되돌리기**: 가져오기 전 자동 보관된 시점을 골라 전체 상태를 되돌립니다.

## ❓ 자주 묻는 질문 (FAQ) & 문제 해결

### Q1. AI 추천이나 지난 결과 시험 버튼이 눌리지 않아요(회색).
> **A.** AI 추천과 지난 결과 시험은 **당첨 정보를 빠짐없이 가져온 뒤**에 쓸 수 있습니다.<br>
> 왼쪽 메뉴의 **`[설정·최신 정보]`** 화면으로 이동하여 **[최신 정보 가져오기]** 또는 **[빠진 회차 모두 채우기]**를 눌러주세요. 준비가 끝나면 바로 풀립니다.

### Q2. QR 확인 또는 엑셀 저장을 누르면 오류가 나요.
> **A.** 기본 설치 외에 추가 기능(`opencv-python`, `pyzbar`, `openpyxl`)이 필요한 경우입니다. 터미널에서 다음 명령어를 실행해 주세요:
> ```bash
> pip install -r requirements-optional.txt
> ```

### Q3. 내가 저장한 번호와 설정 파일은 어디에 보관되나요?
> **A.** 사용자 홈 디렉토리의 아래 경로에 안전하게 보관됩니다:
> - **Windows**: `C:\Users\<사용자명>\.lotto_generator\`
> - **macOS/Linux**: `~/.lotto_generator/`
> - 주요 파일: `app_state.json` (통합 상태), `lotto_history.db` (당첨 SQLite DB)

### Q4. 이전 버전에서 쓰던 번호가 사라지나요?
> **A.** 아닙니다. 앱 실행 시 이전 파일(`favorites.json`, `history.json`, `settings.json`)을 자동으로 찾아 새 저장 형식(`app_state.json`)으로 안전하게 옮겨줍니다.

### Q5. "이미 실행 중입니다"라는 메시지가 나와요.
> **A.** 앱은 한 번에 하나만 실행됩니다. 이미 켜져 있는 창을 찾아보세요. 프로그램이 비정상 종료된 뒤라면 다음 실행 때 자동으로 정리되니 그대로 다시 실행하면 됩니다.
